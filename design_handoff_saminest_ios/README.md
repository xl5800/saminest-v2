# Handoff：Saminest iOS 界面优化（方案 1a）

## Overview
对 `xl5800/saminest-v2` 现有 App 的一轮界面优化：暖色中性底 + 品牌蓝 #315BEA，覆盖首页信息流、帖子详情、找搭子列表/详情、发布、消息、我的、设置、登录注册、举报、反馈，以及管理后台 6 个模块。另外有几项功能改动（见「功能改动清单」），需要改 UI 也需要改逻辑。

## About the Design Files
本目录里的 `.dc.html` 是 **用 HTML 做的设计参考原型**，用来展示预期的外观和交互，**不是要直接拷进项目的代码**。任务是在现有代码库（React 19 + Vite + Tailwind v4 + react-router + TanStack Query + Supabase + Capacitor）里，按现有的组件、目录结构和写法 **重新实现** 这些设计。

- 用浏览器打开 `Saminest App.dc.html` 即可看到可点击的手机原型（需同目录的 `support.js` 和 `Saminest Phone.dc.html`）。
- 所有界面、状态、交互逻辑都在 `Saminest Phone.dc.html` 里：模板是 HTML（内联 style），逻辑在底部 `class Component` 的 `renderVals()` 中。原型里的数据全是假数据，实现时接现有 repository / query hooks。
- 图标：原型用 Phosphor（`ph ph-*`），项目里现在用 `lucide-react`，**继续用 lucide**，挑语义相同的图标即可。

## Fidelity
**高保真**。颜色、字号、圆角、间距以本文 Design Tokens 为准，布局以原型为准。字体继续用项目现有系统字体栈（原型里的 Inter 只是预览用，不要引入）。

## 功能改动清单（优先实现）

1. **全局配色换成暖色中性**：只改 `src/index.css` 的 `@theme` 里中性色的值，蓝色系不变（见 Design Tokens）。
2. **页面标题用品牌蓝**：首页「Saminest」、找搭子页「找搭子」、消息页「消息」、所有二级页 TopBar 标题、登录页「Saminest」→ `text-primary`。卡片内标题保持 `text-text`。
3. **「我的」页去掉帖子/活动/收藏数量统计**（`profile-page.tsx`）。
4. **详情页底部操作栏重排**
   - 帖子详情：左「收藏」（图标+文字，52px 宽）｜中「私信咨询」（实心主按钮，flex:1，高 46px，圆角 8px）｜右「分享」。
   - 找搭子活动详情：左「收藏」｜中「报名参加」（实心主按钮；已报名显示「已报名 · 退出」为描边样式；满员显示「已满员」禁用）｜右「分享」。**不要**「咨询」按钮。
5. **找搭子详情页新增**
   - **「已加入 · N 人」名单**（保留在方形头像格下方）：每行 40px 圆形头像 + 第一行「昵称 {age}岁 · 住{地区}」（沿用现有 activity-detail-page 的拼接规则：age / 地区为空时省略对应段，不留多余分隔符）+ 第二行简介（`text-sm text-text-muted`）。发起人那行名字后加「发起人」小标签（`bg-primary-light text-primary`, 12px, 圆角 4px）。点击行进入对方主页。
   - **评论区**：「评论 · N」标题、输入框 + 「发送」按钮、评论列表（30px 头像、昵称 · 时间、内容、「回复」）。可直接复用帖子的 `comment-section` / `comment-item`，数据表需要支持 activity 作为评论目标（或新建 activity_comments，参照 comments 表）。
6. **地区精确到州，覆盖全美 50 州 + DC**（数据用现有 `src/data/us-states.ts`，展示用 `formatStateLabel` →「NY 纽约州」）
   - 首页 / 找搭子顶部地区胶囊 → 打开底部弹层「选择地区」：搜索框（支持缩写或中文，如 NY、纽约）+ 列表（第一项「全部地区」，其余 51 州按 A–Z），选中项 `bg-primary-light` + 蓝色对勾。
   - 选中州后首页帖子、找搭子活动都按州过滤；线上活动在任何州都显示。
   - 空状态：地图图标 +「{地区} 还没有内容」+「换个地区看看，或者发布第一条」+ 两个按钮「切换地区」（描边）「去发布」（实心）。
   - 发布帖子：原「城市」改为「所在州」（点开同款州选择弹层，无「全部地区」项）+ 下方新增「城市 / 具体位置」文本输入。
   - 发起找搭子：地区从 DC/VA/MD 三选一改为同款州选择（需要 `locations` 表补齐其余州的 `type='state'` 行，或活动改存 `state_code`）。
   - 编辑资料「常驻地区」同样改为州选择。
7. **管理后台保留原版全部功能并优化**（见下方「管理后台」）。在「全部帖子」和「举报处理」里**新增对帖子的「下架」**（原版帖子只有删除）。

- 切换页面回到顶部；进入聊天滚到底部；聊天输入回车发送。

- Action Sheet / 底部弹层：遮罩 `rgba(38,34,30,0.38)`，点击遮罩关闭。
