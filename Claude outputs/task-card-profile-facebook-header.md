## 背景

`src/pages/profile/user-profile-page.tsx`（公开个人主页，`/users/:userId`，"我的"页头像点进去、活动发起人卡片点进去、帖子详情页发帖人卡片点进去，都是同一个页面）目前是 22 号卡做的 Meet5 风格——整个页面顶部是一张通栏正方形头像大图（`aspect-square w-full`，直接用 `avatarUrl` 裁剪展示，没有图片时是纯色块+首字母）。

这次要改成 Facebook 风格：顶部是一块纯装饰性的深色渐变色块（**背后没有真实图片**——这一点已经跟你确认过，不新增"封面图"字段、不做上传功能，工作量上等同于加一段 CSS，不涉及新的数据/存储逻辑），圆形头像压在深色区和浅色区的交界线上（半盖深色、半盖浅色，带一圈浅色描边，"悬浮"层次感，这一点也跟你确认过是照抄 Facebook 那种压线效果，不是头像整个落在浅色区里）。头像右边并排是昵称，下面依次是：个人简介、年龄、"发布的作品"网格。

**不要**给这次改动新增"封面图"这个概念（数据库/Storage/表单都不用动），**不要**做成头像整个落在浅色卡片里、深色区只是单独一条装饰带的版本（跟你确认过是要压线的悬浮效果，不是这种）。

## 具体改法

`ProfileSummary`（`src/components/profile-summary.tsx`）现在只剩"我的"页专用的 56px 横排紧凑卡片这一种布局（22 号卡已经把公开主页用的 96px 居中头像变体删掉了，见文件顶部注释）——这次不要往这个组件里加第三种布局，公开主页这次要的压线悬浮效果跟这个组件现有的两种形态都不一样，直接在 `user-profile-page.tsx` 内部写这段新 JSX（延续这个文件本来就没有复用 `ProfileSummary` 的做法）。

替换掉现在的"通栏正方形头像"那一块（`data.avatarUrl ? <img ... aspect-square .../> : <div ...首字母.../>` 那一段），换成：

1. **顶部装饰色块**：固定高度（建议 `h-28`~`h-32`，具体数值按视觉效果微调），背景用 `bg-gradient-to-b from-primary to-primary-dark`（渐变两端直接用现有的 `--color-primary`/`--color-primary-dark` token，不引入新颜色——`DESIGN.md` 里"全站只用一支蓝"这条约束在这次改动里同样适用，不要因为这是"装饰性色块"就顺手加一个新的中性灰/黑渐变）。这一块背后不放任何 `<img>`，纯 CSS 背景。
2. **圆形头像压线**：紧跟在装饰色块下面另起一个浅色内容区（背景 `bg-card` 白色，区别于全站页面画布的 `bg-bg`——这是这次改版特有的"整块白卡片"处理，不是常规的单个卡片样式），头像用负上外边距把自己拉到装饰色块和这块白色区域的交界线上（比如头像 `h-24 w-24 rounded-full`，配合 `-mt-12`——负值是头像高度的一半，让头像视觉上正好一半盖住深色区、一半落在浅色区），再加一圈 `ring-4 ring-card`（白色描边，做出"悬浮在交界线上"的层次感，不加描边的话头像边缘会跟装饰色块的颜色直接贴在一起，看不出分层）。没有头像时的兜底样式（首字母占位）照抄现在这段代码已有的处理，只是尺寸/位置按新布局调整，不用重新设计一套判断逻辑。
3. **昵称并排在头像右边**：头像和昵称放在同一个 `flex` 行里（`items-end` 让昵称底部跟头像底部对齐，比较接近参考图里的排布），不是像现在这样昵称另起一行、独占一整行。
4. **头像/昵称这一行下面依次**：个人简介（`data.bio`，跟现在一样，`data.bio` 为空整段不渲染）→ 年龄（`data.age`，`PublicProfile` 类型和 `getPublicProfile()` 已经在查这一列了，见 `profiles-repository.ts`，**不需要改仓库层**，纯前端加一行展示，`data.age` 为 `null` 时这一行不渲染，展示成"XX 岁"这种简单文案，不用做成年龄段/星座这类推断）→ 发消息/屏蔽按钮（保持现有位置和逻辑不变）→"发布的作品"标题+网格（保持不变）。

现有的悬浮返回箭头（左上角）、悬浮"更多操作"菜单（右上角，举报用户）都是 `fixed` 定位、不依赖下面内容区域的高度，这次改动不用动它们，颜色（白色图标+半透明黑底）在新的蓝色渐变背景上对比度依然够，不需要额外调整。

## "我的"页联动改动（`src/pages/profile/profile-page.tsx` + `src/components/profile-summary.tsx`）

这是之前讨论过、你确认要一起做的联动改动：

- `ProfileSummary` 现在的 `editHref` prop（渲染卡片右上角的铅笔图标，点击去 `/profile/edit`）要去掉，换成一个新的 `profileHref` prop——渲染同一个位置的圆形图标按钮，图标换成能表达"查看主页"语义的（比如 `UserRound` 或 `ArrowUpRight`，不用铅笔），点击跳到调用方传入的地址（"我的"页传 `/users/${currentUserId}`，跟现在 `avatarHref` 指向的是同一个地址——头像本身继续保留可点跳转，这个新按钮是多一个更显眼的、专门的入口，两者指向同一个目标页面不算冲突，是有意保留的双重入口）。
- `profile-page.tsx` 调用 `ProfileSummary` 时，`editHref="/profile/edit"` 改成 `profileHref={currentUserId ? \`/users/${currentUserId}\` : undefined}`（`avatarHref` 那一行不用动，继续保留）。
- "编辑资料"这个入口挪进下面的分组卡片列表——在"我的内容"或"账号与服务"这两张 `GroupCard` 里新增一行 `<GroupRow to="/profile/edit" icon={UserPen 或 Pencil} label="编辑个人信息" />`（放哪一张分组卡片、放在第几行你可以按视觉习惯定，不是强制要求；图标你可以继续用 `Pencil`，跟原来卡片右上角用的是同一个图标语义，不用换）。
