# 任务卡：留言区头像展示 + 长按弹出举报（仿小红书）

对应 worktree：`C:\Users\32092\Documents\Codex\saminest-v2-comment-avatar-report`，分支 `feat/comment-avatar-longpress-report`（从最新 `origin/main` 切出——如果"帖子详情页操作区改版"那张卡已经先合并，从合并后的 `main` 切）。

## 背景

帖子详情页留言区（`comment-section.tsx` + `comment-item.tsx`）现在每条留言只有昵称+时间+正文，没有头像；操作行是"回复/删除/举报"三个常驻文字按钮。这次要给每条留言左边加上作者头像，同时把"举报"从常驻按钮改成仿小红书的交互：按住（长按）某条留言才弹出举报选项，不再作为一直显示的按钮占位。

## 1. 每条留言左边加头像+名字

- 先查一下 `CommentNode`（`build-comment-tree.ts`）和它背后的 `comments-repository.ts`/`use-post-comments-query.ts` 这条查询链路，确认评论作者的 `avatar_url` 有没有已经被查出来。如果没有，需要跟着 `author_id`/`display_name` 一起扩展这条查询（参考 `posts-repository.ts` 里 `getPostDetail` 查作者信息时"加一列 avatar_url 一次查出来，不新开请求"的做法），`CommentNode` 类型上加一个 `authorAvatarUrl: string | null`。
- `comment-item.tsx` 现在的头部是 `<div className="flex items-center justify-between gap-2">` 里一个 `<span>`昵称 + 一个时间 `<span>`。这次改成头像（圆形，没有头像时用首字母兜底圆圈——照抄 `person-card.tsx` 或 `post-list.tsx` 里 `variant="wanted"` 卡片已经用过的"bg-primary/10 text-primary 首字母圆圈"这个模式，不用发明新样式）+ 昵称 + 时间 横排。回复（子评论）的头像可以比顶层评论小一点，或者跟顶层统一大小——你自己判断哪个视觉效果更协调，写进完工报告。

## 2. "举报"从常驻按钮改成长按弹出

- 现在的操作行（`回复`/`删除`（仅本人评论）/`举报`）里，去掉"举报"这个常驻文字按钮。
- 改成：长按（touch 场景）或按住某条留言的内容区域，弹出一个"举报"选项——点了之后触发跟现在完全一样的举报表单（`activeAction === "report"` 那一整块，包括举报原因单选、补充说明、提交逻辑，一个字都不用改）,只是触发方式从"点击常驻文字按钮"变成"长按弹出"。
- 弹出的形式不需要照搬小红书截图里那种一大条菜单（问点点/回复/收藏/复制/引用发笔记/私信/不喜欢/举报八九个选项）——这里只需要长按后弹出一个"举报"选项（可以是一个小的浮层/气泡菜单，贴着长按的评论定位，也可以是一个居中的小 sheet，只有一个"举报"按钮），点了之后走回现有的 `activeAction("report")` 流程。具体是气泡菜单还是简化 sheet，你自己判断哪个实现起来更简单可靠，写进完工报告说明选了哪种、为什么。
- 长按手势需要自己写一个小的检测逻辑（`onPointerDown`/`onTouchStart` 计时 + `onPointerUp`/`onTouchEnd`/移动过多时取消），不需要引入额外的手势库；桌面浏览器场景可以用鼠标"按住不放"模拟（`onMouseDown`按住一定时长），不需要做"右键菜单"这种桌面专属交互。
- "回复"和"删除"（本人评论）两个操作维持原样，仍然是常驻按钮，只有"举报"改成长按触发。

## 明确不做的事

- 不改举报表单本身的字段/校验/提交逻辑（`reportReasonCode`/`reportDescription`/`createReportMutation` 这一整套原样保留，只换触发入口）。
- 不做小红书那种"问点点/收藏/复制/引用发笔记/私信/不喜欢"这些跟这个 App 无关的功能，长按菜单/浮层只需要承载"举报"一项。
- 不改"回复"/"删除"两个操作的展示方式。
- 不涉及帖子详情页操作区（分享/咨询/收藏工具栏）的改动，那是另一张任务卡。
- 活动详情页目前没有留言区（BARRY 明确说了"先不做"），本卡不涉及活动页。

## 验收标准

- 每条留言（含回复）左边能看到作者头像，没有头像时展示首字母兜底圆圈，样式跟仓库里其它地方的头像兜底一致。
- 留言操作行不再有常驻的"举报"文字按钮。
- 长按/按住一条留言能弹出举报入口，点击后能正常走完举报提交流程，提交成功后展示"举报已提交"（跟现在一致）。
- 移动端触摸和桌面鼠标场景都能触发长按（用测试模拟指针事件验证，不要求真机测试）。
- 现有留言区测试全部通过，新增测试覆盖"头像展示"和"长按触发举报"这两块改动。
