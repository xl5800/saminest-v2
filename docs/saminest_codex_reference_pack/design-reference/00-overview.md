# Saminest UI 改版 · 任务总览

本次改版范围较大（导航架构 + 11 个页面/弹层），拆成 1 张总览卡 + 6 张执行卡，而不是一张巨型任务卡。原因：每张卡都能独立提给 Codex 跑、独立验收、独立回滚，避免一次改动牵连太多文件导致 review 困难。

## 执行顺序（有依赖关系，建议按序合入）

1. **01-design-tokens-nav.md** —— 必须最先做。建立颜色/间距/圆角 token 和「顶部栏 / 底部 Tab 栏」的可复用规则组件，后面所有页面卡都依赖它，不要跳过直接改页面。
2. **02-home-page.md** —— 首页信息流 + 顶部栏改版
3. **03-category-tab.md** —— 分类 Tab
4. **04-find-buddy-flow.md** —— 找搭子列表 + 详情 + 发起者主页 + 发布搭子内容表单（一条完整用户旅程，放一张卡里保证联调上下文一致）
5. **05-publish-flow.md** —— 首页「+」触发的选择发布类型弹层 + 通用发布帖子表单
6. **06-profile-region-misc.md** —— 我的页头像区收尾 + 后台管理权限判断 + 消息 Tab 顶部栏 + 地区选择页

02～06 在 01 落地后可以并行分给不同的人 / 不同的 Codex 会话跑，彼此改动的文件基本不重叠（除了都会用到 01 里的 TopBar/BottomTabBar 组件）。

## 全局设计 Token（01 会落地，这里先列一遍方便其他卡引用）

| Token | 值 | 用途 |
|---|---|---|
| `--bg` | `#F3F5FA` | 全站页面画布背景（不再用纯白 `#FFFFFF` 做页面背景，只有卡片是白色） |
| `--card` | `#FFFFFF` | 卡片背景 |
| `--blue` | `#3457E8` | 品牌主色 / 强调色（全站不引入除蓝色外的强调色） |
| `--blue-dark` | `#2743B8` | 深一级蓝，用于「找搭子」页专属悬浮按钮等需要和主蓝区分场景的地方 |
| `--blue-light` | `#EEF1FD` | 浅蓝底，标签/高亮态背景 |
| `--blue-soft` | `#C9D5FB` | 更浅一级，空状态占位色 |
| `--text` | `#1C1C1E` | 主文字 |
| `--sub` | `#8A8A8E` | 次要文字 |
| `--sub2` | `#B0B0B5` | 三级文字（如邮箱、极小标签） |
| `--line` | `#ECECEF` | 分隔线 |
| `--chev` | `#C7C7CC` | chevron / 弱化图标色 |
| 圆角 | 8px 小标签、16px 卡片、999px 胶囊/悬浮按钮/头像 |
| 卡片投影 | 无阴影（保持现状扁平风格），仅悬浮按钮和菜单弹层带投影 |

## 顶部栏规则速查（01 会做成组件，02～06 直接复用）

| 页面类型 | 左侧 | 中间 | 右侧 |
|---|---|---|---|
| 首页 | — | 同一行「{所在州} · Saminest」，州名灰、Saminest 蓝色加粗 | 「＋」图标 + 「🔍」搜索图标（不再有文字「发布」按钮、不再有底部悬浮发布按钮） |
| 分类 / 消息 / 我的 | — | 居中页面标题 | 消息=通知铃铛，我的=设置齿轮，分类=空 |
| 找搭子 | — | 居中「找搭子」 | 筛选图标；页面内额外有悬浮「＋发起搭子」按钮（Blue Dark） |
| 二级详情页（找搭子详情/发起者主页） | 返回箭头（圆形按钮） | 空或极简标题 | 「…」更多菜单（收藏/分享/举报都在这里） |
| 创建/表单页（发布搭子内容、发布帖子） | 「✕」关闭 | 居中页面标题 | 文字「发布」按钮（蓝色，加粗） |
| 地区选择等纯二级导航页 | 返回箭头 | 居中标题 | 空 |

所有页面统一：**只有首页保留品牌名「Saminest」，其余所有页面都不出现品牌名**；创建/表单类页面不展示底部 Tab 栏。

## 总验收标准（合完 01～06 后回归检查一次）

- [ ] 全站页面背景统一为 `#F3F5FA`，没有纯白页面背景
- [ ] 除首页外，任何页面都看不到「Saminest」品牌名
- [ ] 除首页外，任何页面顶部都看不到文字「发布」按钮
- [ ] 全站配色只用这一套蓝色层级，没有出现其他强调色（如橙色/珊瑚色）
- [ ] 「后台管理」入口只有管理员账号能看到
- [ ] 找搭子的悬浮按钮点击直接进发布表单，不经过选择发布类型弹层；首页「＋」点击才会弹出选择发布类型
