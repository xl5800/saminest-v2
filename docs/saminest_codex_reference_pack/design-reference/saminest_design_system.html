页面背景处理 Background Treatment

当前 Saminest 多数二级页（找搭子详情、找搭子列表等）是纯白底 + 白卡片，卡片和页面几乎没有区分度，看起来“很白很平”。市面上主流 App 基本都不用纯白做画布，而是用一层浅灰/浅色调把白卡片“托”出来。三种常见做法：
中性浅灰（小红书/知乎）
#F5F5F5 画布 + 纯白卡片
极淡暖灰（Airbnb）
#F7F7F7 画布 + 1px 描边卡片
品牌微调灰（推荐）
#F3F5FA 画布，从品牌蓝里提取的极淡冷灰
推荐第三种：用品牌蓝 #3457E8 提取出一个几乎看不出彩度、但比纯灰略偏冷调的背景色 #F3F5FA，既能把白卡片衬托出层次，又和品牌色保持隐性关联（类似 Notion／Linear 用品牌色调背景的做法），比无差别的中性灰更有识别度。已经把本文档「1 设计 Token」里的 Page BG 从 #F2F2F5 调整为 #F3F5FA，后续所有二级页统一套用这个画布色，不再用纯白 #FFFFFF 做页面背景，只让卡片保持白色。

2导航与顶部栏规则

这是本次改版的核心：Meet5 只在 Activities（首页）顶部出现品牌区，其余四个 Tab 顶部只放页面标题和场景化功能图标，二级详情页只有返回和更多菜单。「发布」按钮从每页顶部撤下，仅在首页变成悬浮按钮。

页面左侧中间右侧备注
首页（Tab 1） — 保留品牌“Saminest” —（撤下发布按钮） 唯一出现品牌名的页面；发布改为页面内悬浮 + 号按钮
分类（Tab 2） — “分类” 页面标题 筛选/排序图标（可选） 不出现品牌/发布；不保留“?”帮助图标
找搭子（Tab 3） — “找搭子” 页面标题 筛选图标 不出现品牌/发布；本页专属悬浮“发起搭子”按钮
消息（Tab 4） — “消息” 页面标题 通知铃铛 不出现品牌/发布；不保留“?”帮助图标
我的（Tab 5） — “我的” 页面标题 设置齿轮 不出现品牌/发布；不保留“?”帮助图标
二级详情页
活动详情 / 找搭子详情 / 会员资料		 返回箭头（圆形按钮，半透明底） 无标题，或极简短标题 “…” 更多菜单（收藏/分享/举报统一收进此菜单） 不出现品牌/发布；页面底部不再平铺次操作行

悬浮发布按钮 Floating Action Button

共两个入口，均为胶囊形状、主色填充、高度约 48px，投影 0 6px 16px rgba(52,87,232,0.35)，悬浮于内容之上、Tab 栏上方约 12–16px，滚动时不随内容移动：
＋ 发布
＋ 发起搭子
左：首页专属，对应全站通用的“发布”动作。右：找搭子页专属，文案改为“发起搭子”，用更深的 Blue Dark 区分场景（不引入新色相），避免用户为了发搭子还要绕回首页。其余三个 Tab（分类/消息/我的）不出现悬浮按钮。

3页面结构

五个主 Tab + 两类二级页的模块顺序（从上到下）。

🏠 首页
  1. 顶部栏：品牌“Saminest”
  2. 精选/公告横幅卡（可选，参考 Meet5 推广卡）
  3. 推荐搭子/成员网格区（头像宫格）
  4. 活动/搭子信息流（卡片列表）
  5. 悬浮“＋发布”按钮
🗂 分类
  1. 顶部栏：标题“分类”
  2. 分类入口宫格/列表
  3. 各分类下的内容流（进入子页面）
🤝 找搭子
  1. 顶部栏：标题“找搭子”
  2. 类型筛选 Chips（吃饭搭子/拼车/健身…）
  3. 地区筛选下拉
  4. 搭子活动卡片列表
  5. 悬浮“＋发起搭子”按钮
💬 消息
  1. 顶部栏：标题“消息” + 通知铃铛
  2. 搜索框
  3. 筛选 Chips（全部/未读/已加入/我发起的）
  4. 会员/Premium 推广行（可选）
  5. 聊天列表行
👤 我的
  1. 顶部栏：标题“我的” + 设置齿轮
  2. 头像信息卡（小头像+昵称+签名+邮箱）
  3. 功能列表卡：编辑资料/我的发布/我的活动/我的收藏/意见反馈
  4. “后台管理”分组 仅管理员账号可见（角色判断，见 4.1 说明）
📄 二级详情页
  1. 顶部栏：返回 + “…”更多菜单（收藏/分享/举报都在此处）
  2. 主视觉（图片轮播 / 头像+人数）
  3. 标题 + 标签
  4. 关键信息（地点/时间/发起人）
  5. 正文描述
  6. 主操作按钮（参与/退出/发消息）

5已确认的设计决策

  1. “找搭子”页需要专属发起入口 —— 增加悬浮“＋发起搭子”按钮，样式同首页“发布”按钮，用 Blue Dark 区分场景，见 2.3。
  2. 二级 Tab 页不保留“?”帮助图标 —— 分类/找搭子/消息/我的四页顶部左侧留空，只保留页面标题（及消息的铃铛、我的的齿轮），见 2 导航规则表。
  3. 不引入辅助色 —— 全站不使用珊瑚橙等新色相，横幅、认证角标等强调元素统一改用 Blue Dark / Primary Blue / Blue Soft 这套蓝色层级，见 1 设计 Token。
  4. 详情页次操作收进“…”菜单 —— 收藏/分享/举报不再平铺在页面底部，统一收进右上角“…”更多菜单，见 2 导航规则表与 3 页面结构。
  5. “后台管理”仅管理员账号可见 —— 前端按角色判断渲染，普通用户不显示该分组和入口，见 4.1 组件说明。
  6. 活动卡片头像放大 —— 参与者头像从 34px 提升到 48px、描边加粗+投影，突出社交吸引力，见 4.3 组件说明。
