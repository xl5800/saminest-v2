# 任务卡：「我的」个人资料页头像区改版

## 背景
当前「我的」（Profile）页面头像区域占用空间过大（大圆形头像约占屏幕高度 1/4），且「编辑资料」是一个独立悬浮的蓝色胶囊按钮，与下方「我的发布 / 我的活动 / 我的收藏 / 意见反馈」等白色圆角列表行的视觉风格不一致。参考 Meet5 App 的 Profile 页布局逻辑做改版。

设计方案已确认，效果参考见随附的 `saminest_profile_redesign.html`（左：现状，右：建议方案）。

## 目标
1. 缩小头像展示区域的垂直空间占用。
2. 将「编辑资料」从独立按钮改为与其他功能入口统一风格的列表行。

## 具体改动

### 1. 头像卡片（原：居中大头像 + 昵称 + 签名 + 编辑资料按钮 + 邮箱）
替换为一张白色圆角卡片，内部横向布局：

- 头像：由约 118px 圆形缩小为 **56px** 圆形，卡片内左侧对齐，右侧留 14px 间距。
- 头像右侧纵向排列：
  - 昵称（如“小王”）：16px，字重 600
  - 个性签名（如“喜欢hiking”）：12.5px，灰色 `#8a8a8e`
  - 邮箱（如“xlw0980@gmail.com”）：11.5px，浅灰 `#b0b0b5`
- 卡片整体内边距 14px，圆角 16px，背景 `#ffffff`。
- 移除原来居中的蓝色胶囊「编辑资料」按钮。

### 2. 功能列表卡片（原：我的发布 / 我的活动 / 我的收藏 / 意见反馈）
在该列表卡片**最顶部**新增一行「编辑资料」，与其余各行保持完全一致的行样式：

- 行结构：左侧图标（22px 宽，居中）+ 中间文字标签（14.5px，flex:1）+ 右侧 chevron 箭头（`#c7c7cc`）。
- 行内边距：上下 14px，左右 14px；相邻行以 1px 分隔线 `#ececef` 分隔，最后一行无分隔线。
- 建议给全部 5 行都补上前置图标（现状截图中列表行是没有图标的，可选做，但视觉上更统一）：
  - 编辑资料：编辑/铅笔类图标
  - 我的发布：文档/列表类图标
  - 我的活动：日历类图标
  - 我的收藏：星标类图标
  - 意见反馈：对话气泡类图标
  - （正式实现时用项目现有的线性图标集，不要用 emoji 占位）

### 3. 不变的部分
- 顶部导航栏（返回箭头 / “Saminest” / 「发布」按钮）保持不变。
- 「后台管理」分组标题及其列表卡片位置、样式保持不变。
- 整体页面的模块顺序（头像区 → 功能列表 → 后台管理）保持不变。

## 验收标准
- [ ] 头像区域整体高度较改版前减少约 50%~60%。
- [ ] 页面不再出现独立的蓝色胶囊「编辑资料」按钮。
- [ ] 「编辑资料」作为列表第一行，与「我的发布/我的活动/我的收藏/意见反馈」行高、字号、间距、分隔线完全一致。
- [ ] 点击「编辑资料」行的跳转逻辑与原按钮保持一致（原有跳转/编辑资料功能不变，仅位置和样式变化）。
- [ ] 昵称、签名、邮箱信息在新头像卡片中完整展示，无遮挡或截断。
- [ ] 深色模式（如项目支持）下颜色适配正常。
