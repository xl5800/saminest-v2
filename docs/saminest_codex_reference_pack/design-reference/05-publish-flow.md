# 任务卡 05：通用发布流程（选择发布类型 + 发布帖子表单）

## 依赖
01-design-tokens-nav.md（TopBar `create` 变体）；02-home-page.md（首页「＋」图标要能触发本卡的弹层）

## 背景
首页顶部「＋」图标是全站通用发布入口，点击后要先选发布类型，再分流到对应表单。找搭子类型直接复用 04 号卡已做的表单，本卡负责弹层本身和「租房/求租/二手」这类通用内容的表单。

## 具体改动

### 5.1 选择发布类型弹层
- 从首页点击顶部「＋」，从底部弹出半屏 bottom sheet，深色遮罩 `rgba(17,24,39,0.4)`，sheet 圆角 20px（仅上边），白底。
- 标题「选择发布类型」，居中，灰色小字。
- 四个选项，纵向排列，每项左侧一个图标 + 文案：「🤝 发起搭子」「🏠 发布租房」「🔑 发布求租」「🛍 发布二手」。默认第一项（发起搭子）用浅蓝底 `--blue-light` + 蓝字高亮，其余三项浅灰底 `#F6F7FB` + 常规文字色。
- 点击「发起搭子」→ 跳转到 04 号卡的「发布搭子内容」表单。
- 点击「发布租房 / 发布求租 / 发布二手」→ 跳转到本卡 5.2 的「发布帖子」表单，并把对应分类预选中。

### 5.2 发布帖子表单（通用，覆盖租房/求租/二手三类）
- 顶部：TopBar `create` 变体，标题「发布帖子」，右侧文字「发布」按钮。
- 字段（按顺序）：
  1. 分类——下拉选择行（当前值 + 向下 chevron），根据入口预选中对应分类
  2. 地区——下拉选择行，默认「不限地区」
  3. 标题——单行输入框
  4. 描述——多行输入框
  5. 价格（可选）——单行输入框，可留空
  6. 联系方式类型——下拉选择行，默认「请选择联系方式」占位灰字
- 创建流程页面不展示底部 Tab 栏。

## 验收标准
- [ ] 首页「＋」点击后弹出的是本卡的弹层，不是直接进表单
- [ ] 弹层四个选项文案、图标、默认高亮项与上述一致
- [ ] 「发起搭子」分支跳到 04 号卡表单；其余三个分支跳到本卡「发布帖子」表单
- [ ] 「发布帖子」表单字段顺序、默认值与上述一致，且分类会按入口预选中
- [ ] 表单页顶部风格与 04 号卡的「发布搭子内容」表单保持一致（✕/返回 + 标题 + 文字发布按钮）
