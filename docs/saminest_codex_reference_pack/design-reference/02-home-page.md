# 任务卡 02：首页改版

## 依赖
01-design-tokens-nav.md（用其 TopBar `home` 变体）

## 背景
首页目前顶部是「← Saminest 发布」，下面还有一条独立搜索框，内容是二手/租房信息流。要把顶部精简、搜索收进图标、发布入口从文字按钮变成图标。

## 具体改动

1. **顶部栏**：改用 TopBar 的 `home` 变体——左侧留空，中间同一行显示「{用户所在州} · Saminest」（如「Virginia · Saminest」），右侧两个图标按钮，从左到右依次是「＋」（发布入口）「🔍」（搜索）。原来的文字「发布」按钮和整行搜索框都移除。
2. **点击左侧州名** → 跳转到「地区选择」页（见 06 号卡）。
3. **点击「＋」** → 弹出「选择发布类型」底部弹层（见 05 号卡）。
4. **点击「🔍」** → 进入搜索态（搜索结果页面不在本次范围内，先接入路由即可，可先用现有搜索逻辑）。
5. **筛选 Chips**：保留「推荐 / 租房 / 求租 / 二手」，选中态用 `--blue` 实心胶囊，未选中态白底灰字。
6. **信息流卡片**：改成两列网格，每张卡片包含：图片（16:9 占位图/实际图片）、标题（1-2 行）、价格（有价格显示如「USD 60」，无价格显示灰色「价格未填写」）、分类标签（浅蓝底 `--blue-light` + 蓝字）、地区文字。卡片圆角 16px，白底，无阴影。
7. 首页**不再**渲染底部悬浮发布按钮（已被顶部「＋」图标取代）。

## 验收标准
- [ ] 顶部左侧文案顺序正确：州名（灰）在前、「Saminest」（蓝、加粗）在后，同一行
- [ ] 顶部右侧只有「＋」「🔍」两个图标按钮，没有文字「发布」按钮
- [ ] 页面里搜索不再是单独一整行输入框
- [ ] 底部没有悬浮发布按钮
- [ ] 信息流卡片两列网格展示，图片/标题/价格/标签/地区齐全
