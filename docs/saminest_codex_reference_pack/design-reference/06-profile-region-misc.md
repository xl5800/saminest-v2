# 任务卡 06：我的页收尾 + 消息 Tab + 地区选择 + 权限判断

## 依赖
01-design-tokens-nav.md

## 背景
把之前单独出过的「我的」页头像区改版、以及本轮新增的消息 Tab 顶部栏统一、地区选择页，收在一张卡里做最后收口。

## 具体改动

### 6.1 我的页
直接复用更早期已经交付过的任务卡 `codex_task_profile_redesign.md` 里的验收标准（头像从大圆形缩小为 56px + 昵称/签名/邮箱同卡片排列；「编辑资料」并入功能列表首行，和「我的发布/我的活动/我的收藏/意见反馈」样式统一）。在此基础上本卡新增一条：

- 「后台管理」分组和入口**只有管理员账号可见**——前端按当前登录用户角色判断是否渲染这一整块（分组标题 + 列表行），普通用户完全看不到，不是显示为置灰/禁用态。
- 顶部栏改用 TopBar `tab` 变体：居中标题「我的」，右侧设置齿轮，无品牌名、无「?」帮助图标。

### 6.2 消息 Tab
- 顶部栏改用 TopBar `tab` 变体：居中标题「消息」，右侧通知铃铛，无品牌名、无「?」帮助图标。
- 其余内容（搜索框、筛选 Chips、聊天列表）不变。

### 6.3 地区选择页
从首页顶部州名点击进入。

- 顶部栏改用 TopBar `nav-only` 变体：返回箭头 + 居中标题「地区选择」，不出现品牌名、不出现「发布」按钮（现状页面沿用的是通用顶部栏组件，这里改成二级导航专属的简洁版）。
- 保留原有结构：搜索框「请输入地址搜索」；「全部城市」+「按热度 / 按字母」切换（选中态蓝色）；州列表——多城市的州（如 NY、CA）右侧带 chevron 表示可下钻到具体城市，其余单一地区的州直接点击即选中并返回上一页。
- 页面背景、列表行样式套用全局 token（背景 `--bg`，分隔线 `--line`）。

## 验收标准
- [ ] 我的页「后台管理」只有管理员账号能看到（建议加一条单测/QA 用例：普通账号登录后确认看不到这块）
- [ ] 我的页 / 消息页顶部都不再出现品牌名「Saminest」、文字「发布」按钮、「?」帮助图标
- [ ] 地区选择页顶部改为「返回 + 居中标题」，不出现品牌名/发布按钮
- [ ] 地区选择页 NY、CA 等多城市州带下钻箭头，单州直接选中返回
