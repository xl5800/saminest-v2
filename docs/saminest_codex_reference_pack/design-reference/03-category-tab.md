# 任务卡 03：分类 Tab

## 依赖
01-design-tokens-nav.md（用其 TopBar `tab` 变体）

## 背景
分类 Tab 目前顶部也是「← Saminest 发布」，要统一去掉，改成纯标题栏 + 分类入口宫格。

## 具体改动

1. **顶部栏**：TopBar `tab` 变体，居中标题「分类」，左右不放图标（无品牌、无发布、无「?」帮助图标）。
2. **内容**：2 列网格，展示「租房」「求租」「二手」三个分类 tile，白底圆角 16px 卡片，纯文字居中，无图标也可（若要加图标，用中性线性图标，不要用 emoji）。
3. 点击任一分类 tile → 跳转到首页的信息流页面，并带上对应筛选态（复用 02 号卡的列表组件，传入筛选参数即可，不需要单独再做一套列表 UI）。

## 验收标准
- [ ] 顶部无品牌名「Saminest」、无「发布」按钮、无「?」帮助图标，只有居中标题「分类」
- [ ] 三个分类 tile 可点击，点击后进入对应筛选态的信息流
