# 任务卡 01：全局设计 Token + 顶部栏/底部 Tab 栏组件

## 依赖
无，最先做。02～06 都依赖这里产出的 token 和组件。

## 背景
目前各页面顶部栏各写各的（大多是「← Saminest 发布」这一套），颜色、间距也没有统一变量，导致每次改版要一页页改。这张卡先把基础设施建好。

## 具体改动

### 1. 设计 Token
把 00-overview.md 里「全局设计 Token」表格里的值，落地成项目里的变量（CSS variables / 主题文件 / 设计 token 文件，按项目现有技术栈选合适形式）。重点：

- 页面背景从当前的纯白 `#FFFFFF` 改为 `#F3F5FA`，卡片保持 `#FFFFFF`。
- 全站不新增除蓝色以外的强调色。

### 2. 顶部栏组件（TopBar）
封装一个可配置的顶部栏组件，支持以下变体（对应 00-overview.md 的顶部栏规则表）：

- `home`：左侧留空，中间是「{州名} · Saminest」同一行文案（州名用 `--sub` 灰色，「Saminest」用 `--blue` 加粗），右侧固定两个圆形图标按钮「＋」「🔍」。
- `tab`：左侧留空，中间居中标题文字，右侧可选一个图标（消息=🔔，我的=⚙️，找搭子=筛选图标，分类=空）。
- `detail`：左侧返回箭头（圆形按钮），中间空/极简标题，右侧「…」更多菜单按钮（点击弹出菜单，菜单内容由调用方传入，找搭子详情/发起者主页会传「收藏/分享/举报」）。
- `create`：左侧「✕」关闭按钮，中间居中标题，右侧文字「发布」按钮（`--blue`，加粗，点击态可做禁用/loading）。
- `nav-only`：左侧返回箭头，中间居中标题，右侧留空（地区选择这类纯二级页用）。

组件不需要自己处理品牌名逻辑——只有 `home` 变体会出现「Saminest」，其余变体调用方传标题文字即可，从源头保证「除首页外不出现品牌名」这条规则不会被后续开发者不小心破坏。

### 3. 底部 Tab 栏
5 项不变（首页/分类/找搭子/消息/我的），仅确认选中态统一用 `--blue`，不再有其他强调色；创建/表单类页面（发布搭子内容、发布帖子）不渲染 Tab 栏。

### 4. 悬浮按钮（FAB）组件
封装一个可复用的悬浮胶囊按钮组件：`background: --blue`（默认）或 `--blue-dark`（找搭子专属），高度 48px，投影 `0 6px 16px rgba(52,87,232,0.35)`，固定在屏幕底部水平居中、Tab 栏上方 12–16px，滚动内容时不随之移动。首页**不使用**这个组件（首页发布入口已改成顶部「＋」图标）。

## 验收标准
- [ ] 项目里能找到统一的颜色/间距/圆角变量定义，页面代码里不再出现散落的十六进制色值
- [ ] TopBar 组件支持上述 5 种变体，且 `home` 变体是唯一会渲染「Saminest」文案的地方
- [ ] 全局页面背景色生效为 `#F3F5FA`
- [ ] FAB 组件可传入 `variant: 'default' | 'dark'` 和文案，用于后续找搭子页
