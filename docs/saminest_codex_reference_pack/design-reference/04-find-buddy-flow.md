# 任务卡 04：找搭子完整流程（列表 + 详情 + 发起者主页 + 发布搭子内容）

## 依赖
01-design-tokens-nav.md（TopBar 的 `tab`/`detail`/`create` 变体、FAB 组件）

## 背景
这四个页面是一条完整用户旅程（找搭子列表 → 详情 → 报名/查看发起人 → 发起者主页 → 发消息，以及列表页发起搭子 → 发布表单），放一张卡里改，方便一次联调走通整条路径，避免拆开后上下文丢失。

## 具体改动

### 4.1 找搭子列表页
- 顶部：TopBar `tab` 变体，居中「找搭子」，右侧筛选图标，无品牌/发布/帮助图标。
- 类型筛选 Chips 保留（全部/吃饭搭子/拼车/健身…）。
- **活动卡片头像放大**：参与者头像从现有 34px 提升到 **48px**，叠放间距收紧到 -12px、白色描边加粗到 2.5px 并加轻投影 `0 1px 3px rgba(0,0,0,0.12)`，让"谁已加入"第一眼可见。
- 悬浮按钮用 01 号卡的 FAB 组件，`variant: 'dark'`，文案「＋发起搭子」。
- **悬浮按钮点击 → 直接跳转到 4.4「发布搭子内容」表单**，不经过「选择发布类型」弹层（那个弹层只在首页「＋」触发，见 05 号卡）。

### 4.2 找搭子详情页
- 顶部：TopBar `detail` 变体，返回箭头 + 「…」更多菜单，菜单内容为「收藏 / 分享 / 举报」三项。页面底部**不再**平铺这三个按钮。
- 头像组 + 人数进度、标题、标签、地点卡片、时间、正文描述，保持现有信息结构。
- 主操作按钮：已报名状态显示「退出活动」，未报名显示对应的「立即报名」（沿用现有文案逻辑即可）。
- **发起人整行可点击**，右侧带 chevron，点击跳转到 4.3 发起者主页。

### 4.3 发起者主页
- 顶部：TopBar `detail` 变体，返回箭头 + 「…」菜单（举报等，具体菜单项由业务决定）。
- 头像 80px 居中、昵称、简介、徽章（如「靠谱搭子」「已认证」）。
- **只保留一个「发消息」按钮**，蓝色实心胶囊，**水平居中显示**——不再有收藏/关注等次要按钮和它并排。
- 下方「TA 发起的搭子」列表，复用 4.1 的活动卡片组件（含放大后的头像样式）。

### 4.4 发布搭子内容表单
- 顶部：TopBar `create` 变体，标题「发布搭子内容」，右侧文字「发布」按钮。
- 字段：分类 Chips（默认聚焦当前搭子相关标签，如「学习搭子」）、封面图上传（选填）、标题输入框、详细描述多行输入框、地点选择行、时间选择行、人数上限步进器。
- 创建流程页面**不展示底部 Tab 栏**。

## 验收标准
- [ ] 找搭子列表页悬浮按钮点击后直接进入 4.4 表单，中间没有类型选择弹层
- [ ] 详情页收藏/分享/举报都收进「…」菜单，页面底部没有平铺这三个按钮
- [ ] 详情页「发起人」行可点击并带 chevron，点击进入 4.3
- [ ] 发起者主页只有「发消息」一个主操作按钮且居中，没有收藏/星标按钮
- [ ] 活动卡片（列表页和发起者主页里复用的）头像统一是放大后的 48px 样式
- [ ] 4.4 表单页顶部是「✕/返回 + 标题 + 文字发布按钮」，不显示底部 Tab 栏
